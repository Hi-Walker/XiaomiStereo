# 小米立体声 / Xiaomi Stereo 2.0.7

本版为控制面板加入月亮主题菜单。可选择「跟随系统」「浅色」或「深色」，程序会在下次启动时沿用所选主题。Windows 高对比度优先。此版本还包含自 2.0.4 以来的窗口及托盘主题适配，以及「恢复居中」按钮边框的布局修复。

> **使用前请关闭或解散小米 App 自带的“立体声组合”和“全屋播放”，使用期间保持关闭。两只音箱分别用 USB 连接电脑。**

**AI 制作说明：本软件由 AI 完成设计、开发与文档编写。** 本项目使用的是 Xiaomi 智能音箱 Pro。

下载 `XiaomiStereo-2.0.7-win-x64.zip`，解压全部文件后运行 `小米立体声.exe`。升级前请从托盘正常退出旧版，并保留现有配置文件和状态目录。首次使用请在「设备设置」选择虚拟播放设备、左音箱、右音箱和备用普通输出。需要 Windows 10 1703 或更新版本的 x64 系统、.NET Framework 4.8 或更高版本，以及可用的虚拟播放设备。虚拟音频驱动需另行准备。`XiaomiStereo-2.0.7-source.zip` 提供源码，`SHA256SUMS.txt` 提供文件校验值。

本版的主题、启动窗口、设置和生命周期软件回归通过。已发布的 EXE 未进行新增硬件播放验收。有关测试结果、首轮资源检查及验证范围，请参阅仓库的[测试与兼容性](https://github.com/Hi-Walker/XiaomiStereo/blob/v2.0.7/docs/VALIDATION.md)。

## English

Version 2.0.7 adds a moon menu to the control panel. Choose **Follow system**, **Light**, or **Dark**. The app remembers your selection on restart, and Windows high contrast takes priority. This release also includes the window and tray theme support added since 2.0.4 and a layout fix for the clipped **Reset to center** button border.

> **Before use, disable or dissolve the Xiaomi app's native Stereo pairing and Whole-home playback groups. Keep both disabled while using this software. Connect each speaker separately to the PC by USB.**

**AI development disclosure:** This software was designed, developed, and documented using AI. This project uses the Xiaomi Smart Speaker Pro.

Download `XiaomiStereo-2.0.7-win-x64.zip`, extract all files, and run `小米立体声.exe`. Before upgrading, exit the old version through its tray menu and keep your configuration file and state directory. On first use, open **设备设置 (Device settings)** and select a virtual playback device, left speaker, right speaker, and fallback output. The app requires Windows 10 version 1703 or later on x64, .NET Framework 4.8 or later, and a working virtual playback device. A virtual audio driver must be obtained separately. `XiaomiStereo-2.0.7-source.zip` contains the source, and `SHA256SUMS.txt` contains the archive checksums.

The theme, window activation, settings, and lifecycle software regressions passed. The released EXE has not undergone new hardware playback acceptance testing. See [Testing and compatibility](https://github.com/Hi-Walker/XiaomiStereo/blob/v2.0.7/docs/VALIDATION.md) for the test results, the earlier resource check, and the scope of validation.
